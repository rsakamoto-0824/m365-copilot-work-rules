# 社内Webアプリのリリース

- 新規アプリは、別指定がなければIISで社内公開でき、Electronでビルドできる構成にする。
- Windows 11とWindows Server 2019の会社環境、既存アプリの公開・ビルド方法を優先する。
- インターネット公開の場合は[internet-app.md](internet-app.md)を参照する。
- 元環境のinternal-webapp-release-kitは、このMarkdown集に含まれない。会社で存在・導入が確認できる場合だけ利用し、未導入なら必要なIIS資材・Electron資材・公開手順の作成案を示す。
- 作業範囲、依存関係、設定値、ビルド方法、配置、権限、動作確認、戻し方をまとめる。
- リリース依頼の承認範囲、対象ブランチとマージ先、Private設定、機密・認証情報の混入を確認する。
- 公開資材の作成、ビルド、コミット、push、マージ、サーバー配置を別々に実施記録する。M365で文案を作っただけでリリース済みとしない。
