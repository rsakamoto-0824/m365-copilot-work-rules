# 記入テンプレート

以下の角括弧部分は入力欄です。未確認の値は空欄またはnullにし、実績や承認を捏造しません。保存先が未設定なら、完成した本文を返します。

## メモ・思考整理

```markdown
---
title: "[内容を表すタイトル]"
created: "[YYYY-MM-DD]"
kind: thinking
status: exploring
tags:
  - thinking
---
# [タイトル]

## 問い
## 確認できた事実
## 解釈・仮説
## 選択肢と評価軸
## 現時点の判断
## 次に確かめること
## 関連ノート・出典
```

通常メモではkind: memoとし、必要な見出しだけにします。

## 要件

```markdown
---
title: "[要件のタイトル]"
created: "[YYYY-MM-DD]"
kind: requirement
status: draft
tags:
  - requirement
---
# [タイトル]

## 背景
## 目的・成功条件
## 想定ユーザー
## 機能要件
- [ ] [入力・動作・期待結果を確認できる条件]
## 入出力データ
## 非機能・制約
## 技術候補
## リスクと未確定事項
## 判断（採用 / 保留 / 却下）
## 次アクション
## 関連ノート
```

## タスク

```markdown
---
title: "[実行する行動]"
created: "[YYYY-MM-DD]"
kind: task
status: inbox
priority: medium
planned_start: null
due: null
estimate_h: null
started: null
completed: null
actual_h: null
tracking_since: null
tags:
  - task
---
# [タイトル]

## 背景・目的
## 完了条件
## 実行項目
- [ ] [行動]
## 関連資料
```

## 日報

既存の会社テンプレートがあればそちらを優先します。

```markdown
# [YYYY-MM-DD] 日報

## 作業記録
- [確認できた作業]

## 成果物
- [実在を確認したファイル・URLと内容]

## クイック記録
## 一日の振り返り
- 完了したこと:
- 持ち越すこと:
- 次の一手:

## 未確認・未実施
```

## 調査・資料パック

```markdown
# [テーマ] 参考資料

## 調査の問い
## 結論と根拠
## 参考情報
| タイトル | 著者・年 | DOI・URL | 内容・役割 | 本文確認 | 保存・登録状態 |
|---|---|---|---|---|---|

## 未取得文献
| 文献 | 参照先 | 理由 | 確認日 |
|---|---|---|---|

## 未解決の問い
## 次に確認すること
```

## 実装引継ぎ

```markdown
# [変更内容]

## 対象ファイル・関数
## 解決する問題
## 変更範囲
## 維持する仕様
## 入力例と期待結果
## 検証方法
## 未確定事項
```
