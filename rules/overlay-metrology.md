# Overlay計測・Zernike解析ルール

Overlay計測、Wafer座標、Zernikeモード分解に適用する。

## 座標と単位

- 300 mm Waferを前提とし、Wafer中心を原点 `(0, 0)` とする。
- 座標単位はmm、計測値とZernike係数の単位はnmとする。
- 有効測定点は半径 $r < 150$ mmとし、$r = 150$ mmを含む外側の点を除外する。
- Shot座標はWafer中心基準の絶対座標、Mark座標はShot中心基準の相対座標とする。
- 解析座標は `x = shotX + markX`、`y = shotY + markY` で求める。

## 前処理と評価

- `WaferId`、計測日時、Shot座標、Mark座標が同じ行を重複とみなす。
- 重複行は計測値X・Yをそれぞれ平均してから解析する。
- 計測値Xと計測値Yは、別々にZernike分解とRMSE計算を行う。
- RMSEは重複処理後の点群で算出する。
- 計測日時は `yyyy/mm/dd hh:mm:ss`、タイムゾーンはJSTとする。

## Zernike

- モード番号はFringe番号を使う。
- 正規化方法は、非正規化またはRMS正規化をAPI引数で選べるようにする。
- 低次成分も出力する。
- 初期設定は5次までとし、最大次数はAPI設定で制御する。

## Shot高次補正

- Shot高次補正を計算する場合は、露光機メーカーごとに以下の式を使用する。
- 各式の項、係数番号、変数、符号を変更しない。
- メーカー間で式を共通化したり、記載されていない項を補間したりしない。

### ASML

```text
dx = k1 + k3*x + k5*y + k7*x^2 + k11*y^2 + k13*x^3 + k19*y^3
dy = k2 + k4*y + k6*x + k8*y^2 + k10*x*y + k12*x^2 + k14*y^3 + k16*x*y^2
```

### Canon

```text
dx = k1 + k3*x + k5*y + k9*x*y + k11*y^2 + k17*x*y^2 + k19*y^3 + k27*x*y^3
dy = k2 + k4*y + k6*x + k8*y^2 + k10*x*y + k14*y^3 + k16*x*y^2 + k24*x*y^3
```

### Nikon

```text
dx = k1 + k3*x + k5*y + k7*x^2 + k9*x*y + k11*y^2 + k13*x^3 + k17*x*y^2 + k19*y^3 + k29*y^4 + k41*y^5 + k55*y^6
dy = k2 + k4*y + k6*x + k8*y^2 + k10*x*y + k12*x^2 + k14*y^3 + k16*x*y^2 + k18*x^2*y + k22*y^4 + k24*x*y^3 + k32*y^5 + k34*x*y^4 + k44*y^6 + k46*x*y^5
```

## 想定データ量

- 1 Lotは最大25 Waferとする。
- 1 Waferは90～170 Shot程度を想定する。
- 1 Shotは通常4 Markとするが、Wafer端や製品・工程条件による増減を許容する。
- 通常ケースは1 Lotあたり最大約18,000測定点を想定する。

## M365での利用

これは元環境で指定された解析条件の移植であり、業界共通の定義と断定しない。会社の仕様書・座標定義と照合し、異なる場合は対象案件の条件を確認する。実測データをこのリポジトリへ入れない。計算を実行していない場合、係数やRMSEを算出済みとしない。
