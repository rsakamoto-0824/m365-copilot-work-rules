# データ分析・Excel・KPI

## 共通手順

1. 決めたいこと、対象期間、粒度（1行が表す単位）、母集団、指標の定義、単位、正本の資料を確認する。
2. 更新日、欠損、重複、型、外れ値、結合キー、結合前後の件数・合計、未知分類を調べる。
3. 定義の異なる集計をそのまま比較しない。差がある場合は期間・フィルター・分母・更新時点をそろえる。
4. 必要な比較だけを計算し、計算式・入力範囲・仮定を残す。実データがなければ分析結果を作らず、必要な列と分析計画を返す。
5. 合計・内訳の整合、ゼロ除算、欠損と0、丸め、日付・通貨・割合を検証する。
6. 結論、根拠、限界、次の判断を示す。因果関係を相関だけから断定しない。

## Excel編集

- 対象ブック・シート・セル範囲を特定し、既存の入力欄・数式・書式を保持する。
- 計算結果の固定値貼り付けより再計算できる数式を使う。使用する関数は会社のExcel版で確認する。
- 既存の結合セル・検証規則・名前付き範囲を壊さない。入力・計算・出力が分かる形にする。
- 新規入力テンプレートには入力箇所の凡例と架空の入力例を付ける。既存ブックへ勝手に例行を追加しない。
- 数式エラー、合計、端の行、スピル範囲、表示形式を実際のExcelで確認する。未実行ならその旨を書く。
- 元スキルのLibreOffice由来の新関数禁止は会社のExcelへ一律に適用しない。

## 分析の使い分け

| 依頼 | 追加する確認 |
|---|---|
| KPI設計 | 意思決定、成果指標、先行指標、悪化させない指標、定義・責任者・更新頻度・目標の根拠 |
| KPI報告 | 実績、目標、前期、差、対象期間、比較可能性、根拠のある要因、次の対応 |
| 指標の変動 | 変化時点、全体と内訳、構成比変化と群内変化、寄与、反証する切り口 |
| 市場規模 | TAM/SAM/SOMの対象、数量×単価、重複、到達可能性、上下限、感度分析 |
| 施策判断 | 規模、増減、広がり、集中、単位当たりの強さ、効果とコスト、代替案 |
| データ品質 | 影響範囲、件数と分母、重大度、根拠例、修復案、未確認事項 |
| ダッシュボード | 誰が何を判断するか、指標定義、期間・フィルター、更新日、空表示、詳細への導線 |

## 再現性と納品

分析条件、式またはSQL、入力データの版、実行環境、確認結果を残す。ノートブックを依頼された場合は、初期状態から順に実行できる構成にし、隠れた状態に依存しない。
表やグラフにはタイトル、単位、期間、出典、必要な母数を記載する。比較は棒、時系列は線、分布はヒストグラム等、問いに合う表現を選ぶ。色だけで意味を区別しない。資料・数値の検証後に結論を確定する。
