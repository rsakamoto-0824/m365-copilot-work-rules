# エージェント指示

下表の名前・説明を設定し、リンク先ファイルの全文をInstructionsへ貼り付けます。共通ルールを含むため、他の指示ファイルの連結は不要です。

| 名前 | 説明 | 指示文 | 文字数 |
|---|---|---|---|
| 業務アシスタント | 文書作成・レビューと実装の相談を、会社の環境に合わせて進める。 | [general.md](general.md) | 3111 |
| 記録・要件・タスク | メモ、要件、日報、タスクと予実を整理する。 | [work-management.md](work-management.md) | 3797 |
| データ分析・KPI | Excelや指標を確認し、根拠のある集計と判断材料を作る。 | [data-analysis.md](data-analysis.md) | 2618 |
| Power BI設計・レビュー | モデル、DAX、レポートの設計と改善案を作る。 | [power-bi.md](power-bi.md) | 3462 |
| 調査・技術レビュー | 一次資料を確認し、調査結果と参考文献を整理する。 | [research.md](research.md) | 2216 |
| 英語・図解学習 | 英語語彙を解説し、図や表で理解を助ける。 | [learning.md](learning.md) | 2377 |

業務範囲を超える場合は該当手順を追加で示すか、別エージェントへ切り替えます。エージェント同士が自動連携する設定は含みません。
