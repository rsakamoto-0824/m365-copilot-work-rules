# M365 Copilot 業務ルール・スキル集

個人のCodex環境にある共通ルール・専門ルール・スキルの考え方を、会社のMicrosoft 365 Copilot向けに再構成したMarkdown集です。2026-09-15版。

## 最初に使うもの

1. [設定手順](SETUP.md)を開く。
2. [カスタム指示](instructions/chat.md)の全文をCopilot Chatの設定へ貼る。
3. 業務別に[エージェント指示](agents/README.md)を1つ選んで貼る。または[ノートブック指示](instructions/notebook.md)と必要な資料を使う。
4. [確認用プロンプト](VALIDATION.md)で、会社の環境での応答を確認する。

M365にこのリポジトリを自動読込させる設定ではありません。GitHubへの保存とM365への設定反映は別作業です。会社テナントへの設定・アップロードは未実施です。

## 前提

会社はWindows 11とWindows Server 2019。M365 Copilotを先に使い、GitHub Copilotへのコード依頼は対象と回数を絞ります。会社でCodex・Claude Codeデスクトップ版や、個人のMac・アカウントが使えることを前提にしません。

個人情報、業務データ、認証情報、会話履歴、個人用の保存先は収録しません。会社固有の補足は会社が承認した保管先で管理してください。このPrivateリポジトリに会社資料を追加してよいという意味ではありません。

## 更新

Markdownを正本とし、変更は作業ブランチとPRで確認します。更新後はM365側の貼り付け文・参照資料も手動更新し、確認用プロンプトを再実行します。リポジトリを更新しても貼り付け済みの指示は更新されません。

必要な環境変数やAPIキーはありません。特殊なCLI、プラグイン、追加契約なしでも指示文をコピーして使えます。
