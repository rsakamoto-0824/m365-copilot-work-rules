# 業務別手順

これはM365に貼り付けたり、参照資料として登録したりする手順書です。Codex用の実行可能なSKILL.mdパッケージではありません。依頼時は、手順名と対象資料を指定します。

| 依頼 | 手順 |
|---|---|
| メモ・思考整理・要件化・日報 | [記録と要件](work-management.md) |
| タスク・予実・週次レビュー | [タスクと予実](tasks.md) |
| 日本語の文書レビュー | [日本語文書レビュー](document-review.md) |
| コードレビュー・実装依頼 | [コードと引継ぎ](code-review.md) |
| Excel・集計・KPI・分析 | [データ分析](data-analysis.md) |
| Power BI・DAX・レポート設計 | [Power BI](power-bi.md) |
| Word・PowerPoint・PDF | [文書とプレゼンテーション](office-documents.md) |
| 論文調査・文献整理 | [調査と文献](research.md) |
| 構成図・可視化・画像 | [図と可視化](visualization.md) |
| 英単語・熟語・TOEIC | [英語語彙](vocabulary.md) |
| Obsidian固有形式・保守 | [Obsidian互換手順](obsidian.md) |
| ツール・連携・自動化 | [連携の境界](integrations.md) |

全手順に[共通ルール](../rules/common.md)を適用します。参照資料として置いただけで毎回全文が取得・遵守される保証はないため、必須事項はエージェント指示へ入れ、重要な案件では該当手順を会話にも明示します。
